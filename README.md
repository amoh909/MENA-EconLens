# MENA EconLens 📊

An economic data visualization and analysis platform focusing on the Middle East and North Africa (MENA) region. Built with Django (Backend) and React/Vite with TypeScript (Frontend).

## Features (In Progress..)
- **Data Exploration:** View historical economic trends for 15 MENA countries.
- **Key Indicators:** Track GDP Growth, Inflation, Unemployment, Debt, and more.
- **Advanced Insights:** Dynamic line charts, automated trend summaries, and linear trend forecasting.
- **Comparisons:** Compare data across multiple countries or multiple indicators seamlessly.

## Tech Stack
- **Backend:** Python, Django, Django REST Framework, PostgreSQL
- **Frontend:** React, Vite, TypeScript, Tailwind CSS, Chart.js / Recharts
